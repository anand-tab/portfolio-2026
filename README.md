# Sumanshu Anand — Portfolio

A dark, premium, interactive portfolio starter built with React, TypeScript, Vite, Framer Motion, and Lucide icons.

## Requirements
- Node.js 20.19+ or 22.12+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Design system
- Background: `#090b0d`
- Surface: `#101416`
- Accent: `#c8ff45`
- Main type: Manrope
- Monospace labels: DM Mono
- Borders: translucent green-grey
- Motion: restrained entrance animations, subtle orbital movement, hover lift, tab transitions
- Accessibility: keyboard focus rings and reduced-motion support
